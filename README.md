# Pact

Package manager.

## Usage

``` 
pact push [<executable>]              Push a new release. If no executable filename is given, the programme
                                      will search for one with the same name as the current working directory.
                                      It will generate a project info file from README.md in the current
                                      directory.
```

## Setup

To compile and install using `make` and [install](https://gitlab.com/lfknudsen/install):
```
make
```
